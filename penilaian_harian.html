Koneksi Spreadsheet Gagal!

Aplikasi web tidak berhasil melakukan pertukaran data dengan Google Apps Script Anda. Mohon lakukan pengecekan panduan konfigurasi berikut ini:

📋 Panduan Diagnosis Sistem:

1. Pastikan Anda telah men-deploy ulang Apps Script Anda ke "Versi Baru" (New Version).

2. Pastikan otorisasi akses diset menjadi "Who has access: Anyone" (Siapa saja, bahkan tanpa akun Google).

3. Pastikan tab lembar kerja bernama "siswa" sudah ada di Spreadsheet Anda.

4. Pastikan data siswa Anda di sheet dimulai pada baris ke-3 (Kolom B untuk NIS, Kolom C untuk Nama).
